岗位名称：Java AI Agent 应用开发工程师

岗位职责：
1. 负责 AI Agent 应用后端服务设计与开发，建设可观测、可扩展的智能应用链路。
2. 基于 Spring Boot、Spring AI 或 LangChain4j 接入大模型能力，完成 Prompt 编排、工具调用、RAG 检索和多轮会话管理。
3. 设计并实现向量数据库检索链路，支持文档解析、Embedding、相似度检索和上下文增强生成。
4. 负责业务系统与 AI 能力的工程化集成，包括缓存、异步任务、失败重试、限流降级和日志追踪。
5. 持续优化大模型输出稳定性、响应延迟和用户体验。

任职要求：
1. 3 年以上 Java 后端开发经验，熟悉 Spring Boot、MySQL、Redis 和常见分布式系统设计。
2. 熟悉至少一种 AI 应用开发框架，如 Spring AI、Spring AI Alibaba、LangChain4j。
3. 熟悉 RAG 基本流程，了解 Milvus、Elasticsearch、pgvector 等检索组件之一。
4. 有 Prompt 工程、结构化输出、工具调用或 Agent 编排经验优先。
5. 具备良好的工程化意识，能处理模型调用超时、重试、降级、缓存和可观测性问题。
