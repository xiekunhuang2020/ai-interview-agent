岗位名称：Java 后端性能优化工程师

岗位职责：
1. 负责核心业务系统后端开发，保障订单、支付、用户和运营数据链路稳定。
2. 参与数据库设计、慢 SQL 分析、索引优化和高频接口性能调优。
3. 设计 Redis 缓存、分布式锁、限流降级、幂等和异步处理方案。
4. 参与系统压测、容量评估、线上问题排查和稳定性治理。
5. 与前端协作完成管理后台、运营看板和数据分析功能。

任职要求：
1. 3 年以上 Java 后端经验，熟悉 Spring Boot、MyBatis、MySQL、Redis。
2. 熟悉 MySQL 执行计划、索引设计、事务和常见 SQL 优化方法。
3. 熟悉 Redis 缓存治理、分布式锁、Lua 脚本和热点数据保护。
4. 熟悉 Linux、Docker、Nginx，具备线上部署和问题排查经验。
5. 熟悉 Vue 3、Element Plus、TypeScript 者优先。
